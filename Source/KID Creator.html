Keyword choices and compatibility

Check several tags together; each checkbox changes only its own keyword. Slot filtering hides unrelated options without removing selected tags. Show all tags overrides filtering in both categories and the bulk dropdowns. Bulk options follow checked items, or visible items when none are checked. Custom slot conventions vary; use Show all tags when needed. The editable keyword field and dropdown checkmarks stay in sync. AND, SLA and DD tags can share the same INI. Family checkboxes above control export without clearing your choices. Suggestions use the previous name and slot rules, but slot suggestions now add missing keywords even to already-tagged items. Running Suggest again can restore a suggested tag you removed. Coverage and slot assumptions still need review. Keyword tagging does not create functional DD devices. Existing plugin keywords and other KID files are not removed by unchecking a tag here.
